# Support

Veritas is pre-alpha software maintained on a best-effort basis.

- Use GitHub issues for reproducible defects and narrowly scoped feature proposals.
- Use the documentation and existing issues before opening a new report.
- Do not use public issues for vulnerabilities; follow the [security policy](SECURITY.md).
- Production deployments, data recovery, incident response, and compatibility with unreleased configurations are not supported.

Only the active development line receives fixes. APIs, configuration, schemas, containers, and operational procedures may change without compatibility guarantees before 1.0.
